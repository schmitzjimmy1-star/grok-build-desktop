## Deliberately excluded

The archive does not contain `.env`, local Claude permission settings, API keys,
OAuth or Keychain material, `~/.grok` sessions and transcripts, application
support databases, caches, crash reports, build intermediates, or rollback app
bundles. Those are machine state or sensitive user data, not portable source.
